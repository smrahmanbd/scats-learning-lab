Learn SCATS by running it

The Sydney Coordinated Adaptive Traffic System adjusts cycle length, splits and offsets every cycle from stop-line loop data. This lab teaches it in three levels, with simulators you can drive in the browser and a full SCATS-style controller for Eclipse SUMO.

What is in the lab

Browser simulators

Fifteen interactive models: a live intersection, a DS calculator, the cycle and split algorithms, a time-space diagram, marriage logic, gap-out timers, transit priority and four research experiments, including an RL agent you train in the browser.

SUMO controller

A Python/TraCI SCATS controller with tactical and strategic layers, a four-intersection corridor, baselines and 10 scripts that reproduce every figure on this site.
